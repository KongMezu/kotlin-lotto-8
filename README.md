# kotlin-lotto-precourse
## ✨구현 기능 목록
### 🧾 로또 기본 기능
**1. 로또 구입 금액 입력**
- 구입 금액 입력
- 1000원 단위로 나누어 떨어지지 X -> 예외
- 입력된 금액을 기준으로 로또 개수 계산
- 당첨 번호를 쉼표로 구분해 입력 받는다. + 보너스 번호

```
입력: 8000
입력 : (당첨 번호 쉼표로 구분)

```

**2. 로또 추첨**
-`Randoms.pickUniqueNumbersInRange(1, 45, 6)` 이용
- 1~ 45 w중복 없는 6개의 번호를 뽑는다. 
- 구매 개수만큼 로또를 발행하고, 각 로또 번호는 오름차순 정렬하여 출력한다
```
출력: 8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```

**3. 당첨 결과 계산**
- 일치하는 번호 개수 계산
- 일치 개수 + 보너스 번호 포함해서 등수를 결정
```
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
```

**4.수익률 계산**
- 등수별 당첨 개수의 합 구함
- 구입 금액 대비 수익률을 계산(소수점 둘째 자리까지)
```
총 수익률은 62.5%입니다.
```


### 🚨 예외처리
예외 상황 시 에러 문구를 출력 단, 에러 문구는 "[ERROR]"로 시작
1. 로또 번호 개수가 6개가 아닐 경우 : [ERROR] 로또 번호 6개를 선택하셔야 합니다.
2. 1~ 45 범위를 벗어난 번호 일 경우 : [ERROR] 로또 번호는 1부터 45 사이의 숫자이어야 합니다.
3. 번호 중복 : [ERROR] 중복된 번호가 있습니다.
4. 1000원으로 나누어 떨어지지 않을 경우 : [ERROR] 구입 금액은 1000원 단위여야 합니다.
